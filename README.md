# stm32-led-blink
STM32 NUCLEO-F103RB LED Blink Example using HAL library

# STM32 LED Blink Project

This is a simple GPIO control project using **STM32CubeIDE** with the **STM32 NUCLEO-F103RB** board.  
The LED blinks at 0.5-second intervals.
